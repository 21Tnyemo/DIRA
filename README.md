# Dira

AI and data-driven crop price forecasting with Swahili advice for smallholder farmers in Tanzania.

Prototype using simulated sample data for Morogoro, Tanga, Kilimanjaro, Mbeya and Singida.

- Price trend and 14-day forecast with a confidence check (advice is withheld if the model does not beat a simple baseline)
- Swahili advice with voice playback
- USSD (`*150*77#`) and SMS simulator that work with no internet
- Works offline after the first visit (service worker)

Live: https://21tnyemo.github.io/DIRA/
